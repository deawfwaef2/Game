# 闭门365 / THE LAST TENANT

**v0.18.0-preview：每种东西都不一样**：每条产品线都有自己的描述和真实生效的特色，各家厂牌风格不同；罐头、瓶子、纸盒和书都有了各自的外形与封面。

离线、中文、第一人称3D生存原型。安德士帝国，1986年：你招惹了黑帮，告别家人，带着300帝国纸币藏进高层旧公寓。不开门，活过365天。

## 直接游玩

下载根目录 **`index.html`**，用现代浏览器双击打开即可。不需要安装、联网、服务器、CDN或密钥；3D引擎、模型、贴图与所有资源均已内嵌。打包好的 **`Game-playable.zip`**（含源码与资源）作为GitHub Release附件发布，不再放进仓库本体。

想先验房间质感，打开 **`index.html#sample`**（或在标题页点“先看写实房间样片”），会直接进入可操作房间。样片按300预算合法购入全年单，**袋子原样堆在门边，由你自己拆开摆放**；入室后同样不能再买，**样片不写入/覆盖正式存档**，返回标题恢复之前的游戏对象。

## v0.18 新增：每种东西都不一样

- **每条产品线都有自己的一句话和一个真的特色**，不再只是“厂牌 + 规格”的换皮。商品卡上分成几行：一句口语描述（斜体），橙色“特色”，用途，厂牌风格，产地与批次。所有特色都按游戏里实际实现的效果来写。
  - 食物，部分举例：
    - 西瓜、绿豆汤、酸梅汤、绿豆：热天解暑。冷天吃没有这个效果。
    - 姜枣茶、蜂蜜、冰糖雪梨：感冒时病程缩短约 8 小时。薏米：缓解肠胃不适。
    - 榨菜、腐乳、花生米：自动配一碗煮好的米饭或面一起吃。
    - 家乡风味糯米一类“回忆”食物：只有第一次吃时心情明显变好。
    - 香米一类耐饥的食物：之后几个小时饿得慢。
    - 晚上喝咖啡或绿茶：睡不踏实，体力恢复变少。小米：睡得更沉。
    - 糖水橘子罐头这类水果：吃过后一段时间内，感冒有一半机会躲过去。
  - 生活用品：
    - 盆栽：吊兰能吸一点灰（每天少一点脏），芦荟在生病时每天帮你回一点健康，君子兰在冬天让人心里暖一点，发财树在低落时给一点希望。
    - 鸡毛掸子也能每天少一点灰。
    - 毛巾被、电热毯、枕巾让睡眠更好。草编蒲团、秋衣秋裤、衬衫带来一点舒适。
    - 铁皮米缸能让存粮变质得慢一些。
  - 消遣：
    - 磁带必须有收音机才能放。口琴、空竹会被邻居听见，可疑度 +3。
    - 毛线、十字绣、剪纸、画册、拼图、木头模型做满次数后，会做成一件成品，例如围巾、窗花或拼好的画。日记里会记下来，之后心情下降得慢一点。成品目前还没有单独的 3D 模型。
    - 军棋深夜更好玩，跳棋下雨天更好玩。塔罗牌每次结果都不一样。
- **厂牌各有风格**：例如胜利“老牌国营，封口严实，保质期长一成”，南港“出口转内销，品相好”（贵约 25%，更好吃），群众“最便宜，用料一般”。同一个产品线，不同厂的价格、口味、保质期确实不同。
- **外观**：
  - 罐头有大小罐、高矮罐、玻璃瓶和纸盒之分，罐身印着各自的颜色和品名。
  - 书按当年的开本做成真实大小：小说是 32 开，散文和传记是大 32 开，连环画、棋谱、菜谱是 16 开。厚度看页数，封面印着体裁、书名和出版社，颜色随体裁。
  - 书桌上的书一本压一本地平放成摞，不再和桌上的本子穿模，也不会悬空。
- 目录现为 19,788 种，因为植物和单一规格的产品线不再拆出没有意义的大小包装。每局仍然只到货约 200 种（约 1%）。

## v0.15 新增：一个说得通的家

- **不再出现违和的事情**：所有邻居故事、楼里的动静、窗外的事件，都要对得上当时的钟点、季节和窗外天气才会发生。
  - 下雨才有“窗外下起了雨”，打雷只在温暖季节的雨里出现。
  - 彩虹只在雨刚停后的白天出现，“天空特别蓝”只在晴天。
  - 工厂汽笛在下班时间，挂钟敲十二下在正午或午夜，球赛在晚上。
  - 带“深夜”“早上”“傍晚”的邻居故事会等到那个钟点再发生，不会被跳过，也不会提前。
  - 暖气管只在冷的季节响，烤红薯的香味只在冷天飘来。
  - 节日按时辰来：建国日烟花在傍晚七点，第一声鸟叫在清晨六点，生日在中午。
  - 冬天不会再来“热浪”，来的是暖湿的南风；夏天来的是北风。
  - 删掉了窗外看不到的“大雾”和蝴蝶（虫子）。雪景里“飞蛾”的比喻也改掉了。
- **前一个租客**：这屋子以前住过一个人，按种子是四种人生之一：独居的老钟表匠、带着儿子的母亲、退休的语文老师、开夜班电车的小夫妻。每种人生留下六处痕迹，一年里在打扫、修理、洗衣、洗碗、看窗时一处一处被你发现，最后一处会把这个人的故事收尾。
- **梦**：好好睡上四个小时以上，醒来时有时会记得一个梦，内容和你的处境有关：饿了梦见吃的，冷了梦见雪地，被搜查时梦见脚步声，心情好时梦见家人，读过家信会梦见写信的人。同一个梦一局只做一次，醒来时会轻声说一句。
- **冰花**：室外够冷的夜里和早晨，外层玻璃会从窗框边缘、窗棂边和底部长出羽毛状的冰花，白天慢慢化掉。偏暖的种子不会结冰花，这时“最冷的几天”会换成另一段描写。

## v0.14 新增：会动的身体、看得见的天气

- **身体会动**（只有到了那种状态才会出现）：冷到一定程度时画面一阵阵发抖；极度疲惫或病重时视线缓慢摇晃；饿极了手会发抖。
- **缓过来时也有感觉**：吃饱了说“胃里暖起来了”，喝了水说“整个人活过来了”，睡够了、暖和过来了、洗干净了、剪了头发指甲、上完厕所也各有一句，同时画面微微一暖。只说一次，状态在门槛附近来回波动时不会重复。
- **声音**（暂停菜单里打开声音才有）：饿的时候肚子偶尔咕噜一下；病重时能听到自己的心跳；下雨时有雨打窗台的声音，拉上窗帘会小一些。
- **窗外真的有天气**：阴天里有时会下雨，冬天冷时会下雪，由种子决定。偏暖的种子一冬都不下雪，偏冷的种子会有十几到二十几天下雪。下雨时空中有雨丝，外层玻璃上挂满水珠，雨停后慢慢干。下雪时雪花在空中飘，雪后外窗框底下会积起一道雪，回暖后化掉。今年第一场雪会在开始下的时候记一笔。雨天在窗边看街（Shift+E）有雨天和雪天专属的画面，心情加得多一点；下雨的夜里睡得更安稳。
- **偶尔冒出的念头**：闲下来、没什么急事时，偶尔会想起家人、帮派、过去和以后。会根据下雨、下雪、早晨、傍晚、深夜挑合适的念头，同一个念头一辈子只出现一次。
- **生日由种子决定**：每局不同，也不会和其他节日撞在同一天。

## v0.13 新增：用身体感受状态，不看数值

- **平时屏幕干干净净**：状态正常时没有任何提示和效果。
- **到了才有感觉**：

| 状态 | 什么时候开始 | 画面 | 心里话（举例） |
|---|---|---|---|
| 饿 | 饱腹低于30 | 颜色变淡，四周变暗，越饿越明显；很饿时边缘轻轻泛红 | “肚子咕咕叫了。”→“饿得发慌，手有点抖。” |
| 渴 | 饮水低于30 | 画面发黄、发虚 | “嘴唇发干。”→“喉咙干得发疼，头有点晕。” |
| 困 | 体力低于25 | 变暗、变虚，眼皮慢慢合上又睁开，越困眨得越慢、越久；极困时眼皮半垂 | “眼皮发沉。” |
| 低落 | 精神低于38 | 世界慢慢褪成灰色 | “心里空落落的。” |
| 生病 | 生病或健康低于55 | 四周随心跳泛红 | “身上不太对劲。” |
| 冷 / 热 | 室温低于13°C / 高于28°C | 冷：边缘结霜发白；热：泛暖色 | “冷得直搓手。” |

- 需要上厕所、该洗澡、头发指甲长了、屋里太乱，也只在真的到了那一步时说一句。同一件事3个游戏小时内不重复说；状态更严重时会再说一句。睡觉时不打扰。
- 底部只剩外面的事：敲门、停电、停水。
- **一年里的日子**：发薪日、建国日烟花、盛夏、丰收节、白杨变黄、你的生日、新年夜和新年第一天、最冷的几天、第一声鸟叫、白杨发芽；天冷后还会下第一场雪。

## v0.12 新增：日常的真实感

- **性格**（每局两种，由种子决定，第2天写进日志，日历页上也能看到）：会做饭、睡得浅、书虫、手巧、爱干净、乐天、恋家、夜猫子、会种东西、饭量大。效果都不大，但会改变这一年的节奏。

## 新增：手机友好的定点移动

## 第一天

1. 在供销社用300纸币规划365天资源，全年配给单可作预算起点；短期样例不足一年。查看余粮热量、份数与保质期，到收银台按E确认唯一一次采购。
2. 回房后看向门边袋子，E解开袋口，再E伸手取出一组物品；自己对准储物架隔板、冰箱隔层、桌面或地面按R放下。单只塑料袋不超过8kg，大件独立装箱。
3. 水槽E接水喝；空手看向水槽按R接满储水容器，准备应对随机停水。
4. 从储物架拿食物。需烹煮的先到电炉前E烹煮，再使用手中的饭。吃饭时准星有小光圈QTE；也可以不抢节拍，等它慢慢吃完。
5. 在场景中上厕所、洗澡、洗衣、开衣柜换衣、扫地。读书从书桌拿起，再使用手中的书。
6. 睡前Tab检查状态，到床边调小时后E睡觉。危险或敲门会中断跳时，不会强行睡到死亡。

饥饿/饮水/体力/精神/清洁/健康均为正向指标，越高越好；大小便数值越高越需要处理。常驻HUD仅显示日期、时刻、必要提示与当前物体操作。

133商品与10个实体分类货架（旧降级目录另含“全部”）；价格、重量、份数、热量、保质期。种子影响公寓面积/镜像、床、冰箱、磨损和温度。饮食、储水、排泄、睡眠、疾病、精神、口味重复、读物厌倦、腐败与断电冷藏、清洁、头发指甲、衣物洗换仍由同一套持续模拟负责。随机停水停电不是每局固定必发。

**没有虫鼠，也没有任何替代它们的东西。**房间脏了只影响心情、卫生和健康。

**确认进入公寓后，本局永久禁止购买、补货和送货。**未用完的纸币不再是可换物资的资源；只有明确新开一局才能重新进入准备采购。继续/导入旧存档保留已有库存，但不会恢复交易权限。原有供水/电力与开局房内固定资源不变。

## 存档与边界

- 自动本地存档，Esc可导出/导入JSON；兼容旧v3存档。新增物品摆放位置经过有限值/公寓边界校验。
- 本地存储属于当前浏览器/来源，不会上传。网页沙盒可能限制存储或下载，建议下载HTML在自己的浏览器中玩。
- 不按现实离线时间结算消耗。
- 这是原型：人物手部、吃喝和家务是程序化简化动画；货架以代表性包装显示库存，不能理解为逐粒模拟全部粮食。
- 物品是射线选取和安全表面摆放，不是带重力、堆叠或投掷的完整刚体物理；家具尚不能任意搬动。
- 真实外出、监狱、黑帮追捕、完整烹饪配方、整本小说内容尚未制作。不会把这些说成已实现。

### 保存大型版本时的工作区上限
若Git松散大HTML/ZIP对象会突破128MB，可用`tools/safe_checkpoint.py -m "说明" -- 需提交的文件...`。它在同盘/var/tmp复制完整Git、提交、打包、fsck后原子交换，不删除历史；会拒绝并发元数据变化或超过安全限额。认证仍只通过临时进程，工具本身不保存密钥。
