# 闭门365 / THE LAST TENANT

**一个可以直接下载、离线双击游玩的中文第一人称3D公寓生存原型。**

安德士帝国，1986年。你招惹了黑帮，告别家人，带着300帝国纸币藏进无人知晓的高层旧公寓。不开门，活过365天。

## 立即游玩

1. 下载根目录 **`index.html`**，用现代浏览器直接打开。
2. 或下载 **`Game-playable.zip`**，解压，打开其中的 `index.html`。
3. 无需联网、安装依赖、服务器、CDN或密钥。所有代码、3D引擎和纹理都内嵌。

> GitHub网页会显示HTML源码，请点击文件的下载按钮，不要把源码页当成游戏运行页。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | W A S D |
| 观察 | 按住画面拖动鼠标；可在设置中尝试鼠标锁定 |
| 交互 | 走近家具、准星对准后按 E |
| 物资 | I |
| 房间/所有家具操作 | Tab |
| 消遣 | B |
| 睡眠与时间 | T |
| 手记 | J |
| 关闭面板/暂停 | Esc |

手机：左下摇杆移动，拖动画面观察，右下E交互。所有操作也可通过底部「房间」面板完成。WebGL不可用时，仍可用面板玩生存循环。

## 第一局建议

- 采购页选择「基础清单」再按喜好调整，或挑战「全年紧缩计划」。自动清单不是必胜攻略。
- 进入房间，打开「房间→门边采购袋」拆袋，未拆物资不能使用。
- 接水喝、装满水壶，选食物吃。食用QTE可选择「慢慢吃」跳过操作挑战。
- 别忘了上厕所、洗澡、换衣和打扫。准备多种食物与读物。
- 饥饿、饮水、体力、清洁、健康和**精神均为正向指标**，越高越好；大小便是压力，越高越该处理。
- 睡觉前先处理需求。长时间行动会在危险红线或敲门时自动中断。

## 已实现

- 参数化种子公寓、第一人称行走与家具交互、昼夜灯光、窗外高层城市、旧家具与厨房/独立卫浴。
- 129种商品，11类目录，价格/重量/份数/热量/保质期；8kg塑料袋与大件独立箱，拆袋、分区收纳。
- 饮食与QTE、饮水与储水、睡眠、大小便、精神与健康、疾病持续效果、重复饮食与消遣。
- 保质与冷藏、随机停水停电/天气/敲门、清洁与垃圾、指甲/头发/衣物。
- 抽象小汽车/直升机/足球，概率检查与对应道具；**没有真实虫鼠和恶心画面**。
- 自动本地存档、JSON导出与导入、365天胜利和失败流程。
- 可选地下投递，只能使用剩余纸币，商品加价+配送费，并增加风险记录。

## 原型边界

当前是可扩展原型，不是完整商业游戏。户型是面积/镜像/状态变化，摆放是桌面/储物架/冰箱分区；复杂物理拖拽、真实外出/监狱/追杀、完整配方与营养素系统尚未制作。详见 `DESIGN.md`。不会把这些未完成内容说成已实现。

## 存档

- 本地自动存档只属于当前浏览器/文件来源，不会上传。
- 推荐定期在「存档」导出JSON，浏览器数据被清理后仍可导入。
- 网页沙盒可能禁用localStorage或下载，游戏仍可临时运行；建议下载HTML在自己的浏览器打开。
- 不按现实离线时间结算饥饿、腐败或死亡。

## 开发与协作

编程前必读根目录 **`HANDOFF.md`**，只追加阶段记录，不覆盖其他agent交接。修改 `src` 后立即运行：

```bash
python tools/build.py
```

构建先检查JS语法，再原子替换根目录HTML，随后更新ZIP。无生产运行依赖。Three.js r160.1使用MIT许可，见 `src/vendor/THREE-LICENSE.txt`。

Playwright浏览器测试脚本位于 `tests/`，测试依赖与浏览器应安装到 `/tmp`，不要让工作区超过128MB。版本0.3.0。
