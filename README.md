# 闭门365 / THE LAST TENANT

**v0.10.0-preview：给这一年一个往下过的理由——床头有一叠家人写好的十六封信，每封写着“第几天再拆”；收音机每天播新闻，跟着灰鸦会一案走完一整年，还有天气预报和每周一集的广播剧；窗台上能种葱、发豆芽、养樱桃番茄。虫鼠和替代它们的小汽车、小直升机、小足球已经全部删除。全程不出门，开局只采购一次。**

离线、中文、第一人称3D生存原型。安德士帝国，1986年：你招惹了黑帮，告别家人，带着300帝国纸币藏进高层旧公寓。不开门，活过365天。

## 直接游玩

下载根目录 **`index.html`**，用现代浏览器双击打开即可。不需要安装、联网、服务器、CDN或密钥；3D引擎、模型、贴图与所有资源均已内嵌。打包好的 **`Game-playable.zip`**（含源码与资源）作为GitHub Release附件发布，不再放进仓库本体。

想先验房间质感，打开 **`index.html#sample`**（或在标题页点“先看写实房间样片”），会直接进入可操作房间。样片按300预算合法购入全年单，**袋子原样堆在门边，由你自己拆开摆放**；入室后同样不能再买，**样片不写入/覆盖正式存档**，返回标题恢复之前的游戏对象。

## v0.10 新增：愿意过完365天的理由

- **家里的信**：床头柜上有一叠用绳子捆好的信，是分别前一晚爸、妈和妹妹小禾写的，共十六封，最后一封在第360天。走过去按 E 解开绳子、抽出信，两只手拿着读；滚轮可以翻看以前拆过的信。没到日子也能 Shift+E 偷偷先拆，但精神加得少，计数也会记下来。到日子那天早上，日志会提醒你。
- **收音机真的在播**：7点、12点、18点前后是新闻。一年里有27条新闻，讲灰鸦会一案从仓库起火、专案组成立、首领潜逃，到被捕和最后宣判。有几条会说附近有人挨户敲门，之后两三天敲门明显变多；听到了就能提前拉好窗帘、保持安静。每次新闻后都有明天的天气预报，和窗外是同一套天气。每逢第6、13、20……天晚上8点播广播剧《雾港旅馆》，一共26集，错过了下周接着播。其他时间是音乐节目。字幕会在画面下方淡入淡出。
- **窗台小菜园**：开局买“陶土花盆与培养土”，再买葱头、发芽绿豆或樱桃番茄种子，就能对着窗台上的花盆种。葱大约9天剪第一茬，能剪6次；豆芽4天一盆，不要光，但每天要浇水；番茄约50天开花，之后每隔几天能摘一把。阳光越多长得越快（拉着窗帘只剩三成光，阴天更少），太冷长得慢，土干久了会枯死。每次浇水用0.25升。收下来的菜直接拿在手里，放在哪里由你自己决定。自己种的东西吃起来心情更好，也能缓解一直吃同样东西的乏味。
- **删除虫鼠及替代物**：几何干扰物系统、检查家具、三种清理道具都已移除。房间脏了只影响心情、卫生和健康。手电筒改成停电时检修更快。旧存档里如果还带着这些数据，读档时会自动清掉。

## v0.9 新增：待在屋里也看得见时间

- 太阳按游戏时间走一条弧线：日出约6:24、日落约18:36，从窗户左侧升起、右侧落下；直射光透过窗洞在地板和墙上投下带窗格影子的光斑，随钟点移动。早晚阳光偏暖，深窗洞会挡住很低的斜阳。
- 天气按“种子+天数”确定（读档后同一天不变）：约三成阴天（没有直射光，窗外光更平更白），部分日子有薄雾；第一天总是晴天。窗外天空、远景和室内面光源颜色跟着变化，黄昏和夜晚之间是平滑过渡。
- 马桶：一体式座便器（底座、碗体、存水、后部台面、水箱、盖板、镀铬按钮）、热塑座圈、靠在水箱上的翻盖、地脚螺栓帽，以及接到墙上角阀的软管。
- **不出门**：这是一个从头到尾待在屋里的游戏，外出不是待办功能。

## v0.8 新增：光照与建筑本身更真实

- **光照修正**：此前环境贴图一直以满强度照亮所有表面（three r160 不支持 `scene.environmentIntensity`，旧代码的设置无效），房间因此又平又灰。现在按材质缩放环境反射（金属单独保留），白天主要光来自窗户：新增与窗洞同尺寸的面光源，靠窗亮、房间深处逐渐变暗，天花板只接到反射光；夜里吊灯是暖色主光。
- **环境光遮蔽（GTAO）**：家具底下、墙角、物品之间出现柔和接触阴影，在 HDR 中计算后只做一次色调映射。暂停菜单可开关“环境光遮蔽”；触屏设备和软件渲染默认关闭，帧率持续过低会自动关闭并提示（手动打开的则保持开启）。玻璃、透明物和不可见交互代理不会投下遮蔽。
- **窗户重做**：约40厘米深的抹灰窗洞，室内外两层油漆木窗（窗框、中梃、横档、三扇可开窗扇和小气窗），带灰色油灰线、执手、合页；内层玻璃有擦拭痕和角落积灰，外层有干掉的雨痕；宽木窗台板和外侧镀锌泄水板。油漆有刷痕、发黄和少量掉漆。
- **暖气**：11片铸铁暖气片（MS-140式样）装在单管立管上，带上下支管、旁通管、铜阀和墙托，取代原来的胶囊形占位。
- **卫生间**：1.2米搪瓷坐浴盆（卷边、排水口、橡胶塞、龙头下的锈迹），双把混水龙头、长出水嘴、软管和挂墙手持花洒；L形浴帘杆和印花塑料浴帘拉在一侧；洗衣盆放进浴盆里；门洞有门框和贴脸，门扇向内开着，上部是压花玻璃。
- **电气**：墙上胶木圆形插座（台灯插头和电线、冰箱插头、厨房台面上方双插座、床边插座），卫生间门外双联开关。
- **床**：格子羊毛毯按床垫实际高度铺盖并从床沿垂下，上沿翻折着白色床单。
- **厨房水槽**：以前碗体单面渲染，从上面看会直接看到柜子；现在是有深度的不锈钢水槽和排水口。

## 规则底线与目前边界

采购会话不存档恢复；核心结账与入库函数也会拦截重复交易，不是只隐藏门口按钮。此前地下补给由agent自行加入，已按用户纠正删除。**当前是房间样片，不代表商店、129商品包装和所有生活动作都已经达到相同美术质量。**

## 新增：手机友好的定点移动

- 右上角按钮或 **V** 可随时切换“自由行走 / 定点移动”，切换不重置位置。正常主入口在桌面默认自由、手机默认定点；选择会记住。独立样片默认展示定点，但不强制改写正式游戏的偏好。
- 定点模式下，**四边箭头直接标出可去的地点**。点一下按正常步速沿可通行路线走过去，到位后转向物件；拖动仍能环顾。方向随视向变化，无通路的箭头变灰。
- 途中点“停”或切回自由可取消；暂停、读档、新动作/新警报也会停步。不自动购买/使用，不瞬移、不跳时，身体需求照常推进，手中物品保留。
- 商店有14个站点（包括全年配给单/短期样例/收银与十类货架），公寓有床、书桌、厨房、电炉、储物架、冰箱（若有）、衣柜、沙发、卫生间、门口等站点。到位后仍用E或手机交互键做事，不变成菜单。
- 手机在定点模式隐藏摇杆，切回自由就恢复；吃喝、辅助、放回、手记按钮照常可用。

## 新增：窗外与老式相机质感

- 近中景是有真实位移视差的楼体、窗框、窗台、阳台栏杆和屋顶天线，远处才接旧城全景；楼层/布局由种子变化。外景不进入室内射线或碰撞，不代表新增了可外出的城市地图。
- 默认轻微褪色暖调、细颗粒、柔和暗角，**不靠模糊/低分辨率遮细节**；UI文字不套canvas滤镜。Esc中的“胶片画面”可关闭并记住选择，系统减少动态偏好会停颗粒动画。
- 立面和远景仍使用贴图，不代表每扇窗后有建好的室内/NPC。此版本仍是原型，性能与美术质量需在实际设备上继续验证。

## 写实房间样片具体范围

- 旧床、皮沙发、木桌、柜架、随身听与代表性罐头是带PBR材质的真实网格；墙、地板、布料有图像/法线/粗糙信息，不再全靠单色盒子。
- 人手为25关节蒙皮模型，程序化屈指握持；搪瓷杯有中空杯壁，喝水有抬杯与倾转，读物双手持握。不是完整人物骨骼/动捕系统。
- 窗边日光、接触阴影、起伏布帘、金属水槽/中空瓷器与旧公寓细节已接入。窗外城市与画框是生成的装饰纹理，房间自身是真正可走动的实时3D，不是效果图。
- 家具交互体积和实际摆放表面分开：E对家具更宽容，R仍需落在实际网格水平表面，不能把物品悬浮在隐形交互框上。
- **仍待改造**：商店整体、部分简化包装、若干家务动作与人物全身。没有声称所有物件一比一建模、完整刚体物理或高端设备画质/FPS保证。

## 第一天

1. 在供销社用300纸币规划365天资源，全年配给单可作预算起点；短期样例不足一年。查看余粮热量、份数与保质期，到收银台按E确认唯一一次采购。
2. 回房后看向门边袋子，E解开袋口，再E伸手取出一组物品；自己对准储物架隔板、冰箱隔层、桌面或地面按R放下。单只塑料袋不超过8kg，大件独立装箱。
3. 水槽E接水喝；空手看向水槽按R接满储水容器，准备应对随机停水。
4. 从储物架拿食物。需烹煮的先到电炉前E烹煮，再使用手中的饭。吃饭时准星有小光圈QTE；也可以不抢节拍，等它慢慢吃完。
5. 在场景中上厕所、洗澡、洗衣、开衣柜换衣、扫地。读书从书桌拿起，再使用手中的书。
6. 睡前Tab检查状态，到床边调小时后E睡觉。危险或敲门会中断跳时，不会强行睡到死亡。

饥饿/饮水/体力/精神/清洁/健康均为正向指标，越高越好；大小便数值越高越需要处理。常驻HUD仅显示日期、时刻、必要提示与当前物体操作。

## 存档与边界

- 自动本地存档，Esc可导出/导入JSON；兼容旧v3存档。新增物品摆放位置经过有限值/公寓边界校验。
- 本地存储属于当前浏览器/来源，不会上传。网页沙盒可能限制存储或下载，建议下载HTML在自己的浏览器中玩。
- 不按现实离线时间结算消耗。
- 这是原型：人物手部、吃喝和家务是程序化简化动画；货架以代表性包装显示库存，不能理解为逐粒模拟全部粮食。
- 物品是射线选取和安全表面摆放，不是带重力、堆叠或投掷的完整刚体物理；家具尚不能任意搬动。
- 真实外出、监狱、黑帮追捕、完整烹饪配方、整本小说内容尚未制作。不会把这些说成已实现。
