# 闭门365 / THE LAST TENANT

**v0.7.0-preview：写实室内重做——印花墙纸、老式厨房与冰箱、皮革包门、瓷砖卫生间；门边的塑料袋要亲手解开、一件件取出并自己放好，没有任何自动整理。开局只采购一次，入室后只能靠存量生存。**

离线、中文、第一人称3D生存原型。安德士帝国，1986年：你招惹了黑帮，告别家人，带着300帝国纸币藏进高层旧公寓。不开门，活过365天。

## 直接游玩

下载根目录 **`index.html`**，用现代浏览器双击打开即可。不需要安装、联网、服务器、CDN或密钥；3D引擎、模型、贴图与所有资源均已内嵌。打包好的 **`Game-playable.zip`**（含源码与资源）作为GitHub Release附件发布，不再放进仓库本体。

想先验房间质感，打开 **`index.html#sample`**（或在标题页点“先看写实房间样片”），会直接进入可操作房间。样片按300预算合法购入全年单，**袋子原样堆在门边，由你自己拆开摆放**；入室后同样不能再买，**样片不写入/覆盖正式存档**，返回标题恢复之前的游戏对象。

## v0.7 新增：更像真实的旧公寓

- 墙面：1980年代印花条纹墙纸、石膏顶角线、天花板烟熏与楼上旧漏水痕、墙角积灰阴影；地面旧木地板与东方地毯，厨房区老油毡。
- 厨房：灰绿色木柜与抽屉、带水槽开孔的层压台面、长条白瓷砖挡水、吊柜、白色四眼电炉与搪瓷锅。
- 冰箱：修正朝向（门朝房间、靠侧墙），可开门，内有冷冻格、铁丝隔层、果蔬盒、门内搁架与灯；R能把东西放到你瞄准的那层。
- 入户门：绗缝人造革包门、铜钉、门牌、猫眼、门链、锁舌与椰棕地垫；门上方挂钟实时走动。
- 卫生间：墙砖与地砖、立柱面盆、搪瓷洗衣盆、镜子；衣柜/床头柜/储物架换成胡桃木贴皮。
- 塑料袋：真实T恤袋形状（底部方、内容物顶出的鼓包、打结的提手、印刷的商店标志）；打开后能看到袋口露出的东西。
- 商品包装：按商品做纸袋、纸盒、罐、瓶、软包、药盒、布类等不同造型并印有标签；牙刷等小物平放。
- **不自动放置**：E解开袋口，再按E取出一组物品到手上；手满时不能再拿；必须对准桌面、架子隔板、冰箱隔层或地面按R才放下，放不稳会提示原因。旧的“Shift+E整袋自动整理”已经删除。


GitHub文件页面显示的是源码，请点击下载文件，不要把源码页当成运行页。

## 规则底线与目前边界

采购会话不存档恢复；核心结账与入库函数也会拦截重复交易，不是只隐藏门口按钮。此前地下补给由agent自行加入，已按用户纠正删除。**当前是房间样片，不代表商店、129商品包装和所有生活动作都已经达到相同美术质量。**

## 新增：手机友好的定点移动

- 右上角按钮或 **V** 可随时切换“自由行走 / 定点移动”，切换不重置位置。正常主入口在桌面默认自由、手机默认定点；选择会记住。独立样片默认展示定点，但不强制改写正式游戏的偏好。
- 定点模式下，**四边箭头直接标出可去的地点**。点一下按正常步速沿可通行路线走过去，到位后转向物件；拖动仍能环顾。方向随视向变化，无通路的箭头变灰。
- 途中点“停”或切回自由可取消；暂停、读档、新动作/新警报也会停步。不自动购买/使用，不瞬移、不跳时，身体需求照常推进，手中物品保留。
- 商店有14个站点（包括全年配给单/短期样例/收银与十类货架），公寓有床、书桌、厨房、电炉、储物架、冰箱（若有）、衣柜、沙发、卫生间、门口等站点。到位后仍用E或手机交互键做事，不变成菜单。
- 手机在定点模式隐藏摇杆，切回自由就恢复；吃喝、辅助、放回、手记按钮照常可用。

## 新增：窗外与老式相机质感

- 近中景是有真实位移视差的楼体、窗框、窗台、阳台栏杆和屋顶天线，远处才接旧城全景；楼层/布局由种子变化。外景不进入室内射线或碰撞，不代表新增了可外出的城市地图。
- 默认轻微褪色暖调、细颗粒、柔和暗角，**不靠模糊/低分辨率遮细节**；UI文字不套canvas滤镜。Esc中的“胶片画面”可关闭并记住选择，系统减少动态偏好会停颗粒动画。
- 立面和远景仍使用贴图，不代表每扇窗后有建好的室内/NPC。此版本仍是原型，性能与美术质量需在实际设备上继续验证。

## 写实房间样片具体范围

- 旧床、皮沙发、木桌、柜架、随身听与代表性罐头是带PBR材质的真实网格；墙、地板、布料有图像/法线/粗糙信息，不再全靠单色盒子。
- 人手为25关节蒙皮模型，程序化屈指握持；搪瓷杯有中空杯壁，喝水有抬杯与倾转，读物双手持握。不是完整人物骨骼/动捕系统。
- 窗边日光、接触阴影、起伏布帘、金属水槽/中空瓷器与旧公寓细节已接入。窗外城市与画框是生成的装饰纹理，房间自身是真正可走动的实时3D，不是效果图。
- 家具交互体积和实际摆放表面分开：E对家具更宽容，R仍需落在实际网格水平表面，不能把物品悬浮在隐形交互框上。
- **仍待改造**：商店整体、部分简化包装、若干家务动作与人物全身。没有声称所有物件一比一建模、完整刚体物理或高端设备画质/FPS保证。

## 保留的场景交互

- 采购从商品卡片改成了**可走动的3D供销社**：逛十类实体货架，把样品拿入篮中，到机械收银台付款。
- 正常WebGL游玩移除了底部管理菜单、成排状态卡与日常操作弹窗。
- **E直接拿取/使用**。食物拿在手里，主食先去炉边烹煮；吃喝、读书、睡觉、家务在场景中完成。
- 冰箱门、衣柜门、床头抽屉能实际打开。物资可对准桌面/平面按R摆放，也可归还储物架或放入打开的冰箱。
- **实体手记和腕表**替代常驻数值大面板。需要详细状态时再低头翻看，不是删掉生存需求。
- 暂停、导入/导出存档仍保留必要的简洁菜单。旧界面仅在WebGL不可用时作为降级操作方式。

## 操作

| 操作 | 按键 |
|---|---|
| 行走 / 环顾 | 自由模式WASD/摇杆；定点模式点四边箭头；拖动画面环顾 |
| 切换移动方式 | V / 右上角模式按钮；途中“停”取消自动走路 |
| 胶片画面开关 | Esc → 胶片画面 |
| 拿取、开门、使用眼前物品 | E |
| 使用手中物品 / 阅读 | 左键或空格；没有其他目标时也可E |
| 放置到所瞄准的水平表面，或归还物资 | R；商店里是放回一件商品 |
| 查看完整状态、物资情况、日志 | Tab / I / J 翻开实体手记，滚轮翻页，再按一次合上 |
| 抬腕看表 | T |
| 床边调整睡眠小时 | 滚轮 / ↑↓，E躺下 |
| 上厕所 | E小便，Shift+E大便 |
| 辅助动作 | Shift+E，具体动作看向物体时会显示 |
| 手电筒 | F，需要买下并拆出 |
| 暂停、存档 | Esc |

商店：E拿一件，Shift+E拿五件，R放回一件；Tab看纸质购物清单。门边有短期物资样例（约79天理论热量、不足一年）、全年紧缩配给单及收银台，不想逐件挑选时可直接登记整套。清单已有商品时，再取整套会要求第二次E确认替换。

手机：默认用箭头定点移动，也可切回左侧摇杆自由移动；拖动画面环顾；右侧E、辅助、使用、放回、±、手记按钮。床边±调时长，手记里±翻页。无需键盘也可完成生活循环。

## 第一天

1. 在供销社用300纸币规划365天资源，全年配给单可作预算起点；短期样例不足一年。查看余粮热量、份数与保质期，到收银台按E确认唯一一次采购。
2. 回房后看向门边袋子，E解开袋口，再E伸手取出一组物品；自己对准储物架隔板、冰箱隔层、桌面或地面按R放下。单只塑料袋不超过8kg，大件独立装箱。
3. 水槽E接水喝；空手看向水槽按R接满储水容器，准备应对随机停水。
4. 从储物架拿食物。需烹煮的先到电炉前E烹煮，再使用手中的饭。吃饭时准星有小光圈QTE；也可以不抢节拍，等它慢慢吃完。
5. 在场景中上厕所、洗澡、洗衣、开衣柜换衣、扫地。读书从书桌拿起，再使用手中的书。
6. 睡前Tab检查状态，到床边调小时后E睡觉。危险或敲门会中断跳时，不会强行睡到死亡。

饥饿/饮水/体力/精神/清洁/健康均为正向指标，越高越好；大小便数值越高越需要处理。常驻HUD仅显示日期、时刻、必要提示与当前物体操作。

## 保留的生存内容

129商品与10个实体分类货架（旧降级目录另含“全部”）；价格、重量、份数、热量、保质期。种子影响公寓面积/镜像、床、冰箱、磨损和温度。饮食、储水、排泄、睡眠、疾病、精神、口味重复、读物厌倦、腐败与断电冷藏、清洁、头发指甲、衣物洗换仍由同一套持续模拟负责。随机停水停电不是每局固定必发。

只出现干净抽象的小汽车、小直升机、小足球；检查概率发现、总数未知、要对应工具清理。**没有真实虫鼠或恶心画面。**

**确认进入公寓后，本局永久禁止购买、补货和送货。**未用完的纸币不再是可换物资的资源；只有明确新开一局才能重新进入准备采购。继续/导入旧存档保留已有库存，但不会恢复交易权限。原有供水/电力与开局房内固定资源不变。

## 存档与边界

- 自动本地存档，Esc可导出/导入JSON；兼容旧v3存档。新增物品摆放位置经过有限值/公寓边界校验。
- 本地存储属于当前浏览器/来源，不会上传。网页沙盒可能限制存储或下载，建议下载HTML在自己的浏览器中玩。
- 不按现实离线时间结算消耗。
- 这是原型：人物手部、吃喝和家务是程序化简化动画；货架以代表性包装显示库存，不能理解为逐粒模拟全部粮食。
- 物品是射线选取和安全表面摆放，不是带重力、堆叠或投掷的完整刚体物理；家具尚不能任意搬动。
- 真实外出、监狱、黑帮追捕、完整烹饪配方、整本小说内容尚未制作。不会把这些说成已实现。

## 开发与测试

编程前先读根目录 **`HANDOFF.md`**，只追加交接。源码在 `src/`，生产入口始终是根HTML。

```bash
python tools/build.py        # JS语法检查 → 原子生成HTML → 打包ZIP
node tests/simulation.cjs    # 无额外依赖的生存模拟与365天策略
```

浏览器开发依赖只安装在临时目录，不影响零依赖游玩：

```bash

# Linux缺库时另运行 playwright install-deps chromium
NODE_PATH=/tmp/closed365-qa/node_modules PLAYWRIGHT_BROWSERS_PATH=/tmp/closed365-browsers node tests/browser.cjs
# 手机真实tap路线/模式切换/暂停读档/257种子站点路线/真实行走时钟
```

### 保存大型版本时的工作区上限
若Git松散大HTML/ZIP对象会突破128MB，可用`tools/safe_checkpoint.py -m "说明" -- 需提交的文件...`。它在同盘/var/tmp复制完整Git、提交、打包、fsck后原子交换，不删除历史；会拒绝并发元数据变化或超过安全限额。认证仍只通过临时进程，工具本身不保存密钥。
